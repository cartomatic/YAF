# Project Vision

## Overview
YAF (Yet Another Framework) is a .NET DDD framework that provides building blocks for business applications, delivered as a NuGet package.

## Current State
- **Age**: ~2 months (started late February 2026)
- **Status**: Active development — domain layer foundation complete
- **Users**: .NET developers building DDD-based business applications
- **Tech Stack**: C# 10+ / .NET 10, xUnit, GitHub Actions CI/CD

## Purpose
YAF exists as an experiment in AI-driven development: all code is generated by AI (primarily Claude Code), while humans provide architectural decisions, documentation, and quality oversight. The framework itself provides opinionated DDD building blocks (Entity, AggregateRoot, ValueObject, Error, Result) so teams can start business applications with a consistent, well-tested foundation.

## Goals (Next 6-12 Months)
- Build infrastructure layer with persistence abstraction (EF Core adapter)
- Add ASP.NET Core API layer with example web application
- Implement observability infrastructure (structured logging, distributed tracing)
- Publish to NuGet as a reusable package
- Create developer documentation (quick-start guide, API reference)

## Evolution
The project started with domain building blocks and has progressively added DDD patterns: TypedId, Entity, AggregateRoot, ValueObject, memento pattern, cross-cutting concern interfaces (accountability, timestamps, soft-delete, tenancy, versioning), Error with railway-oriented Result pattern. The next phase moves beyond the domain layer into infrastructure and API concerns.

## Differentiators
- **AI-generated codebase** — all code produced by AI, documenting a reproducible AI-driven development process
- **Architecture-first** — 24 ADRs documented before most implementation
- **Strict quality enforcement** — warnings-as-errors, required XML docs, EditorConfig rules, automated formatting checks
- **Memento pattern built-in** — state management support in base entity classes from the start
