# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

YAF (Yet Another Framework) is a .NET framework intended as a starting point for business applications. The project is an experiment in AI-driven development: **all code must be generated by AI, no human-written code is allowed**. Humans provide documentation, plans, decisions, tools, and skills only.

## Architecture Goals

- Modern .NET with DDD, Clean Architecture, IoC/DI
- Scalable, containerized, cloud-ready
- Delivered as a NuGet package with simple project setup
- Includes a web API example application
- High-level decisions documented as ADRs (Architecture Decision Records)
- Reasonable test coverage
- CI/CD pipelines

## Key Constraints

- **No human-written code** — all code is AI-generated
- **Human responsibility** — all decisions (architectural, code quality, bugs) are the human's responsibility
- Preferred AI tool: Claude Code (though other tools like GitHub Copilot may be used)
- Open source from the start; process should be documented and reproducible

## Current State

The repository is in its initial phase — no source code exists yet. Only the project manifesto (`docs/what-and-why-or-the-other-way-round.md`) and scaffolding files are present.
