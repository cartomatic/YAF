Yet Another Framework — a .NET framework for business applications, built entirely by AI.

The twist: **no human-written code**. All code is generated by AI (primarily Claude Code), while humans handle decisions, documentation, planning, and tooling. See the [manifesto](docs/general/what-and-why-or-the-other-way-round.md) for the full story behind the idea.

## Documentation

The `docs/` directory is the backbone of the project — in an AI-driven workflow, documentation is what steers the code, not the other way around.

| Directory | Purpose |
|-----------|---------|
| [docs/general/](docs/general/) | Project foundations — the [manifesto](docs/general/what-and-why-or-the-other-way-round.md) and [dev setup](docs/general/dev-setup.md) instructions |
| [docs/plans/](docs/plans/) | Implementation plans — the "what to build next" before AI generates the code |
| [docs/brainstorms/](docs/brainstorms/) | Exploration of ideas, approaches, and trade-offs before committing to a plan |
| [docs/research/](docs/research/) | Technical research — evaluations of tools, patterns, and libraries |
| [docs/diary/](docs/diary/) | Session diary — honest accounts of working with Claude Code, including what went well, what went wrong, and lessons learned |
