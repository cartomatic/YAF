Yet Another Framework — a .NET framework for business applications, built entirely by AI.

The twist: **no human-written code**. All code is generated by AI (primarily Claude Code), while humans handle decisions, documentation, planning, and tooling. See the [manifesto](docs/general/what-and-why-or-the-other-way-round.md) for the full story behind the idea.

## Documentation

Documentation is the backbone of the project — in an AI-driven workflow, it steers the code, not the other way around.
